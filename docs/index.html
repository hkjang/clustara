Core Features

엔터프라이즈 K8s 운영을 핵심으로 통합

단일 바이너리로 구동되어 설치가 매우 간편하며, 클러스터의 안정성과 보안성을 대폭 높입니다.

🔍

근거 기반 RCA 장애 규명

CrashLoop, OOM, ImagePull, Readiness Probe 오류를 직전 배포 및 Config 변경 이력과 자동 매핑하여 원인 후보 딥링크를 제시합니다.

🛡️

안전 액션 & 터미널 승인

Scale, Rollout Restart, Delete Pod, Exec Web Terminal 접근 시 사전 영향도 평가와 어드민 승인 워크플로우 및 감사 리플레이를 제공합니다.

🌿

GitOps 변경 & Drift 관리

GitLab/Bitbucket 연동을 통해 실클러스터와 Git Source 간 Drift를 실시간 분류하고 PR Draft 및 배포 증적을 통합 관리합니다.

🔒

보안 거버넌스 & RBAC 감시

Pod Security 등급, RBAC 위험 권한 및 RBAC Diff, 이미지 취약점(Trivy/Grype), Secret 만료 및 Falco 런타임 이벤트를 실시간 모니터링합니다.

💰

FinOps 비용 & 용량 최적화

Request×단가 기반 월 예측 비용을 네임스페이스 및 팀별로 추정하고, HPA 진단과 과소/과다 할당 리소스 최적화를 안내합니다.

📦

오프라인 & 폐쇄망 완벽 지원

GATEWAY_SECRET 기반 AES-GCM 암호화, 독립형 SQLite/PostgreSQL 지원 및 폐쇄망 환경을 위한 오프라인 Docker 패키지를 제공합니다.

Architecture & Safety

안전하고 경량화된 읽기 전용 수집

Clustara는 클러스터에 부하나 무분별한 에이전트 수정 권한을 남기지 않고 안전하게 동작하도록 설계되었습니다.

  • ✓
    Zero-Mutation 수집 게이트웨이 수집 과정에서 클러스터를 변경하지 않는 안전한 Read-Only ServiceAccount 수집
  • ✓
    AES-GCM 데이터 암호화 GATEWAY_SECRET을 통한 Kubeconfig 및 Access Token 원천 암호화 저장
  • ✓
    ClickHouse 장기 데이터웨어하우스 적재 변경 이력, 이벤트, 보안 통계, 비용 Fact를 장기 대시보드용 ClickHouse로 자동 sink
Quick Start

단 1분 만에 서버 기동하기

Docker 컨테이너 한 줄 또는 Go 환경에서 바로 기동하여 클러스터를 연결할 수 있습니다.

Docker 컨테이너 실행 (추천) 
docker build -t clustara:dev .
docker run -d --name clustara --restart=always -p 9090:9090 -v $PWD/data:/data \
  -e GATEWAY_SECRET=$(openssl rand -hex 32) \
  -e ADMIN_TOKEN="dev-admin-token" \
  clustara:dev

Go 개발 환경 직접 실행 
export GATEWAY_SECRET="dev-only-secret"
export ADMIN_TOKEN="dev-admin"
go run ./cmd/clustara

# 어드민 UI 접속: http://localhost:9090/admin (토큰: dev-admin)
Frequently Asked Questions

자주 묻는 질문 (FAQ)

Clustara 도입 및 엔터프라이즈 운영과 관련한 핵심 질문과 답변입니다.

Clustara는 CrashLoopBackOff, OOMKilled, ImagePullBackOff, Pending, Readiness Probe 실패 등의 이벤트가 발생할 경우, 수집된 리소스 spec 리비전(append-only 이력)과 직전 배포/YAML 변경 내역을 시점별로 매핑합니다. 이를 통해 단순히 "Pod가 죽었다"는 사실 외에도 "어떤 변경으로 인해 원인이 발생했는지" 후보 목록을 직관적인 딥링크로 제공합니다.

네, 마련되어 있습니다. Scale, Rollout Restart, Cordon, Pod Delete 등의 작업은 '액션 센터(Action Center)'를 거칩니다. 작업 요청 시 영향도 분석이 먼저 수행되며, 어드민 승인 게이트를 통과해야만 실제 실행됩니다. 웹 터미널(exec) 접속 시에도 사전 정책(Role, Namespace, 명령 허용/차단 목록)과 세션 감사 리플레이를 제공합니다.

Clustara는 단일 Docker 이미지 및 독립형 SQLite/PostgreSQL 저장소를 지원하므로 오프라인 폐쇄망 환경에 그대로 배포할 수 있습니다. 저장되는 Kubeconfig, 서비스 토큰, Provider Key 등 모든 민감 데이터는 GATEWAY_SECRET 기반의 AES-GCM 알고리즘으로 강력하게 암호화됩니다.

네. GitLab 및 Bitbucket Server와의 연동을 통해 클러스터 리소스와 Git Source 간 Drift를 감지하고 PR Draft를 자동 생성할 수 있습니다. 또한 위험 이벤트 및 보안 위반 발생 시 Mattermost 채널로 중복 제거 및 담당팀 라우팅 딥링크 알림을 전송합니다.
