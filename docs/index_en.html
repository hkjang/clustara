Core Features

Unifying Enterprise K8s Operations at the Core

Runs as a single binary for effortless installation while greatly bolstering cluster stability and security.

🔍

Evidence-Based RCA Diagnostics

Correlates CrashLoop, OOM, ImagePull, and Readiness Probe failures with recent deployments and config change histories, presenting root cause deep-links.

🛡️

Safe Actions & Terminal Approval

Provides pre-impact assessments, admin approval workflows, and audit replays for Scale, Rollout Restart, Delete Pod, and Exec Web Terminal access.

🌿

GitOps Changes & Drift Management

Integrates with GitLab/Bitbucket to classify live cluster vs Git source drifts in real time, managing PR drafts and deployment audit trails.

🔒

Security Governance & RBAC Audit

Monitors Pod Security levels, RBAC permissions & diffs, container vulnerability scans (Trivy/Grype), Secret expirations, and Falco runtime events in real time.

💰

FinOps Cost & Capacity Optimization

Estimates monthly predicted costs based on Request×Unit Price per team/namespace, guiding HPA diagnostics and resource allocation optimization.

📦

100% Offline & Air-Gapped Network Support

Provides GATEWAY_SECRET-based AES-GCM encryption, standalone SQLite/PostgreSQL support, and offline Docker packages for air-gapped environments.

Quick Start

Launch Server in Under 1 Minute

Launch in seconds via a single Docker command or Go environment to connect your clusters.

Docker Container Run (Recommended) 
docker build -t clustara:dev .
docker run -d --name clustara --restart=always -p 9090:9090 -v $PWD/data:/data \
  -e GATEWAY_SECRET=$(openssl rand -hex 32) \
  -e ADMIN_TOKEN="dev-admin-token" \
  clustara:dev

Direct Go Development Execution 
export GATEWAY_SECRET="dev-only-secret"
export ADMIN_TOKEN="dev-admin"
go run ./cmd/clustara

# System Operational Engine & Enterprise Telemetry UI System Operational Engine & Enterprise Telemetry: http://localhost:9090/admin (System Operational Engine & Enterprise Telemetry: dev-admin)
