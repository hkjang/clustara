Quick Start

Launch Server in 1 Minute

Launch in seconds via Docker single command or Go binary to connect your cluster.

Launch via Docker Container (Recommended) 
docker build -t clustara:dev .
docker run -d --name clustara --restart=always -p 9090:9090 -v $PWD/data:/data \
  -e GATEWAY_SECRET=$(openssl rand -hex 32) \
  -e ADMIN_TOKEN="dev-admin-token" \
  clustara:dev

Run via Go Environment Directly 
export GATEWAY_SECRET="dev-only-secret"
export ADMIN_TOKEN="dev-admin"
go run ./cmd/clustara

# Admin UI Access: http://localhost:9090/admin (Token: dev-admin)
